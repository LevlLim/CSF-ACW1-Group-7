Sample Verification Instructions

All files are in the "Sample Files" folder. The public keys below are raw
Base64 SubjectPublicKeyInfo values accepted by the GUI. These are disposable
demonstration credentials; no private signing keys are included.

Note: The current image and audio files named "*_encrypted" contain signed
payloads but were created without the optional AES-256-GCM checkbox enabled.
The GUI therefore correctly displays "Signed only" for Payload protection.
This note applies to those reusable files in "Sample Files"; the separate
test-evidence screenshots include runs where AES-256-GCM was enabled.


Capacity Failure Checks

Image:
1. Load image_toosmall.png as the cover image.
2. Select 1-bit LSB and enter the large Project Overview paragraph.
3. Generate a signing keypair and select a start pixel.
Expected result: Status shows "Too large" and embedding is blocked.

Audio:
1. Load wav_fail_test_case.wav as the cover audio.
2. Select 1-bit LSB and enter or load at least 12,000 ASCII characters.
3. Generate a signing keypair.
Expected result: Status shows "Too large" and embedding is blocked.
