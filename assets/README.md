# Assets

Sample files for the submission and demo go here: original cover
image/audio, protected (stego) versions, and deliberately tampered copies
used in the negative test cases from `docs/TEST_MATRIX.md`.

Suggested layout once files are added:

```
assets/
├── image/
│   ├── cover.png
│   ├── stego_short.png
│   ├── stego_large.png
│   └── stego_tampered.png
└── audio/
    ├── cover.wav
    ├── stego_short.wav
    └── stego_tampered.wav
```
